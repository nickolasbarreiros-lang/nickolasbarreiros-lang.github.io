# Revisão MACS 1.0 — cinco fichas

As cinco fichas foram revistas com base nas fontes registradas nos JSON individuais. As proporções são **propostas técnicas**, não receitas experimentalmente validadas. A consulta a 25 orquidários brasileiros distintos por espécie **não foi concluída**; não se atribuem notas MACS definitivas.

## Ajustes relevantes
- **B. rothschildianum:** mistura revista para refletir pinus + carvão + musgo documentados por orquidários brasileiros; cachepô continua hipótese principal.
- **B. roxburghii (arquivo histórico B. sikkimense):** comparação entre referências do nome aceito e histórico; umidade regular com drenagem.
- **B. saltatorium var. albociliatum (arquivo histórico B. miniatum):** recomendação publicada para a espécie, não para a variedade, de madeira com esfagno.
- **B. sicyobulbon (arquivo histórico syciobulbon):** crescimento espalhado/trepador, avaliar espaço para rizoma.
- **C. mattosianum:** distinguir crescimento ativo e repouso; literatura de cultivo disponível é sobretudo por gênero.

As fontes estão nos campos `fontes_botanicas` e `produtores_brasileiros` dos JSON individuais, com nível de evidência explicitado.
